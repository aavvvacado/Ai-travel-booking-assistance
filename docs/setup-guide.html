Installation & Setup Guide

Follow this step-by-step guide to clone, configure, build, and run the AI Travel Booking Assistant application on your development workstation or emulator.

Prerequisites

📋 Required Tools
  • Flutter SDK: Version 3.19.0 or higher (stable channel).
  • Dart SDK: Version 3.3.0 or higher.
  • Android Studio / Xcode: For Android device emulators and iOS simulators.
  • Google Gemini API Key: Optional. Required for online LLM reasoning; if left unconfigured, the app seamlessly runs on its Local NLP engine.

Step 1: Clone Repository & Fetch Dependencies

# Clone the project repository
git clone https://github.com//aitravelbookingassistance.git
cd aitravelbookingassistance

# Fetch Flutter package dependencies
flutter pub get

Step 2: Configure Gemini API Key (Optional)

You can provide your Google Gemini API key in two convenient ways:

Option A: Via Application UI Dialog

Launch the application and click the key icon (🔑) in the top-right app bar. Enter your Gemini API key (e.g. AIzaSy... or custom key starting with AQ...) and click Save Key.

Option B: Via --dart-define at Run Time

flutter run --dart-define=GEMINI_API_KEY="AIzaSyYourSecretGeminiApiKeyHere"

Step 3: Run Automated Unit Tests

Verify that all 14 unit tests pass cleanly before launching the app:

flutter test

Step 4: Run Application on Target Device

# Run on connected Android or iOS device/emulator
flutter run

# Run on Chrome for Web testing
flutter run -d chrome
