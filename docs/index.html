AI Travel Booking Assistant

A production-ready voice & conversational flight search and booking application built with Flutter, Clean Architecture, Google Gemini 1.5 Flash LLM, and a zero-config deterministic Local NLP Rule Engine fallback.

🏗️
Clean Architecture
Feature-driven Clean Architecture with decoupled Data, Domain, Presentation, and Service Locator layers.
🧠
Hybrid Gemini LLM
Online LLM intent reasoning with structured JSON schema output and seamless local offline NLP failover.
📅
Date & Layover Engine
Resolves composite expressions like "next month 7", relative dates, and bidirectional layover/duration sorting.
⚡
Setup & Execution
Quick setup, environment variable configuration, unit testing, and mobile build instructions.

Key Features & Highlights

🎙️ Conversational Voice & Text Interface
Seamlessly supports continuous Speech-to-Text (STT) and Text-to-Speech (TTS) audio output with ChatGPT-style thinking and search animation bubbles.
⚡ Zero-Config Hybrid AI Failover
Works out-of-the-box with zero API key configuration via `LocalRuleAiServiceImpl` or online reasoning via `HybridAiServiceImpl` powered by Google Gemini 1.5 Flash.
📅 Advanced Date Resolution
Understands complex temporal queries like "next month 7" (October 7th, 2026 relative to reference date Sep 7, 2026), "next weekend after the 12th", "tomorrow", and explicit day updates.

Architecture Overview

The application strictly follows Clean Architecture principles, ensuring that UI components are completely independent of business logic and external network providers:

Layer Location Responsibility
Presentation Layer lib/features/flight_booking/presentation/ Flutter UI Widgets, VoiceChatBloc (conversational state), BookingBloc (flight data state).
Domain Layer lib/features/flight_booking/domain/ Pure business entities (Flight, SearchCriteria), FlightSearchService, DateResolver.
Data Layer lib/features/flight_booking/data/ FlightLocalDataSource mock dataset (200+ realistic flights across BOM, DEL, DXB, SIN, LHR, JFK).
Core Layer lib/core/ ServiceLocator (GetIt pattern), AiService interface, SttService, TtsService.

Quick Start Code Example

// Searching flights programmatically via ParseUserIntentUseCase
final result = await parseUserIntentUseCase(
  userPrompt: 'Fly from Mumbai to Dubai next month 7 with lesser layover.',
  currentCriteria: const SearchCriteria(),
);

result.fold(
  (aiResult) {
    print('Action: ${aiResult.action}');
    print('Departure Date: ${aiResult.updatedCriteria.dateText}'); // 2026-10-07
    print('Sort Preference: ${aiResult.updatedCriteria.sortPreference}'); // SortPreference.fastest
    print('Matching Flights: ${aiResult.matchingFlights.length}');
  },
  (failure) => print('Error: ${failure.message}'),
);
